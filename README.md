# המחבט – אתר מחבטי טניס

אתר סטטי (HTML/CSS/JS) למכירת מחבטי טניס חדשים ומשומשים, מתארח ב-Vercel.

## עדכון מחבטים
כל המחבטים נמצאים בקובץ `data/rackets.js`. מוסיפים/מוחקים אובייקט ושומרים – כל push ל-`main` מעלה גרסה חדשה לאוויר.

תמונות: שמים קובץ בתיקייה `images/` וממלאים את השדה `photo`, למשל `"images/pure-drive.jpg"`. בלי תמונה מוצג ציור של מחבט.
